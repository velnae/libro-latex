INICIO
    LEER B, n
    SI B no es entero no negativo O n no es entero no negativo ENTONCES
        MOSTRAR "Datos iniciales inválidos"
        TERMINAR
    FIN SI
    total ← 0
    PARA i ← 1 HASTA n HACER
        LEER nombre, q, p
        SI nombre está en blanco O q no es entero positivo
           O p no es entero no negativo ENTONCES
            MOSTRAR "Material inválido"
            TERMINAR
        FIN SI
        total ← total + q * p
    FIN PARA
    saldo ← B - total
    SI saldo >= 0 ENTONCES
        estado ← "Viable"
    SINO
        estado ← "No viable"
    FIN SI
    MOSTRAR total, saldo, estado
FIN
